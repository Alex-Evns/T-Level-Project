# Assignment Brief Summary

## Module
Digital Technology Project

## Assessment
Module Assignment

## Weighting
100%

## Submission requirement
A comprehensive technical report documenting the design, development, testing, and validation of a prototype.

## Main goal
Evolve a foundational hackathon idea into a Technical Proof of Concept (PoC) and Functional Prototype (MVP).

## Six required report sections
1. Project Definition & Scoping (10%)
2. Specialism-Specific Technical Requirements and Risk Register (10%)
3. Design: The Architecture Phase (20%)
4. Implementation: The Build Phase (30%)
5. Testing & Validation (10%)
6. Critical Evaluation (10%)

## Writing requirement
- Maximum 3,500 words
- Professional structure
- Title page and table of contents
- Harvard referencing
- Clear academic writing and formatting

## Software Developer pathway expectations
- Functional specification
- Technical design with UML diagram and system architecture diagram
- MVP with documented code snippets for a critical feature
- Minimum 5 software tests covering edge cases
- Critical evaluation including technology stack decisions and root cause analysis

## Important academic rules
- Academic integrity required
- AI use allowed only as a supplementary tool
- Final work must reflect the student’s own understanding and effort
- Reference AI-generated content and be able to explain it if asked
