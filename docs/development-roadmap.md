# Development Roadmap

## Goal
Deliver a focused MVP within a very short deadline.

## Timeline
### Day 1
- Gather T-Level research and source material
- Write functional specification
- Create architecture and technical design
- Set up environment and project structure
- Build initial frontend shell

### Day 2
- Implement triage questionnaire
- Implement chatbot and knowledge layer
- Build T-Level information page
- Integrate all sections into one app
- Run tests and capture evidence
- Write technical report and final checks

## Priority order
1. Research
2. MVP scope lock
3. Architecture
4. Frontend build
5. Triage logic
6. Chatbot
7. Testing
8. Report writing

## Critical success rule
Do not chase perfect features. Focus on a clean MVP that clearly demonstrates the core idea.

## Final deliverable strategy
The final app should clearly show:
- what T-Levels are
- who they are for
- whether they may be a good fit
- how to ask questions about them

This is the strongest way to satisfy the assignment brief while staying practical under time pressure.
