# MVP Scope

## Core features
### 1. T-Level information page
A dedicated page or section that explains:
- what T-Levels are
- how they are taught
- what industries they lead into
- examples of career pathways
- how they compare with A-Levels and apprenticeships

### 2. AI-powered triage questionnaire
A multiple-choice decision-support system that asks a short series of questions such as:
- preferred learning style
- interests and subjects
- career goals
- comfort with practical/work-based learning

The system returns one of the following categories:
- Strong fit for T-Levels
- Possible fit / explore further
- Less suitable / consider other pathways

### 3. RAG chatbot
A chat interface where users can ask natural-language questions such as:
- What are T-Levels?
- Are T-Levels worth it?
- How do they compare with A-Levels?
- What jobs can T-Level students do?

The chatbot should provide evidence-based answers using curated T-Level resources.

## MVP must-haves
- A polished frontend experience
- T-Level information content
- Triage result screen
- Chatbot integration
- Clear, accessible UI
- Responsive design for common screen sizes

## Nice-to-have features
- Search within chatbot answers
- Suggested follow-up questions
- More detailed visual comparison charts
- FAQ section

## Out of scope for this submission
- User accounts
- Persistent database of user results
- Advanced analytics
- Full admin panel

## Assumption
The app is for information and recommendation only, not for storing user data or personal accounts.
